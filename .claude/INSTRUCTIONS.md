# Project Instructions for Claude

## File Organization

When generating files during development, please follow these conventions:

- **Auto-generated notes, plans, and working documents**: Place in `/planning`
  - Examples: Bug fix plans, implementation summaries, test plans, task breakdowns

- **Documentation**: Place in `/docs`
  - Examples: Architecture docs, API documentation, setup guides, user guides

- **Do NOT** create markdown files in the project root unless they are standard repository files like README.md, CONTRIBUTING.md, etc.

This keeps the repository organized and makes it easier to find relevant documentation and planning materials.
